\chapter{Hasil dan Pembahasan}

Bab ini melaporkan hasil aktivitas \textit{Demonstration} dan \textit{Evaluation} melalui pengujian empiris Hipotesis H1–H4 pada lima dataset utama serta validasi eksternal menggunakan \textit{Smart Building IoT}. 
Seluruh eksperimen dijalankan pada Raspberry Pi 5.
Pengujian H1 menggunakan tiga \textit{seed} dataset dengan lima replikasi algoritma untuk setiap kombinasi dataset dan tingkat dependensi, sedangkan anggaran evaluasi disesuaikan dengan dimensi ruang solusi.
Hasil disajikan berdasarkan hipotesis, meliputi kualitas kebijakan, jejak memori, efisiensi pembaruan dan \textit{warm-start}, validasi eksternal, serta sintesis temuan.
